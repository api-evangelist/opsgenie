Claude Agent for Jira, built on Anthropic's Claude Managed Agents infrastructure, lets users assign work items directly to Claude within Jira, where it processes task context, implements changes in a secure sandbox, and opens draft pull requests for review. It operates within Jira Cloud for managed workflows or connects locally via an MCP server and the Teamwork Graph CLI, and is available on the Atlassian Marketplace for Standard, Premium, or Enterprise customers with Rovo enabled.
